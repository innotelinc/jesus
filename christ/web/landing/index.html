What do you want it to do?

Name the capability. Do not learn the containers.

$ node cli.js select ai
capabilities: models, voice, agents, memory, tools

voice

The floor

Calls, media, routing and the browser softphone on one socket. No SIP, no AMI, no RTP range.

pstn

A real number

A carrier trunk, a DID and caller ID — in the only process that speaks SIP.

platform

VoiceOps

Accounts, extensions, IVR, voicemail, CDRs and the softphone. It writes the routing document; the switch executes it.

agents

The conversation

Capstone and dograh take the call over ARI, with STT, an LLM and TTS around it.

models

One endpoint

OmniRoute in front of every provider, or a local model with nothing leaving the box.

souls

The identity

Souls compiled into prompts: extension, voice, model and the text the agent is spoken from.

The wiring

One declaration in, the switch's whole dial plan out.

carrier14132642700 → gateway → switch
in hoursline 101 → bridge 25s → voicemail
after hoursanswer → ari dograh → the receptionist
outbound1​?????????? → trunk → the carrier

The document is validated with the switch's own router, posted, and then read back — a 200 that leaves the old plan loaded is a failure. The DID is answered in all three forms a carrier might send: eleven digits, ten, and +1.
