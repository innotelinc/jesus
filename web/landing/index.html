the estate · per-project history

Every Innotel product, in one tree.

The voice standard, the telephony platform, the mail client, the training platform, the agent tooling and the gateways — one directory each, each with the commit history it earned. Nothing squashed, nothing re-authored.

Browse the tree What is in here

Why one tree

History is the product

A merged monorepo loses the commit history that explains why each product looks the way it does. Here each directory keeps its own.

The shared contract is stated once

Licence, environment posture, attribution guard and the stack role live at the root, so a new product inherits them instead of rediscovering them.

Each product still builds alone

Per-product workflows run where the code is; the root CI only guards the contract that goes wrong quietly.

One place to see the estate

Fourteen products under apps/ plus the containers that wire them into one voice system.
