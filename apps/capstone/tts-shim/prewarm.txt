# Greetings spoken at the start of every inbound call. The shim synthesizes one
# utterance per line at startup and writes it into the audio cache, so the first
# caller gets a cache hit (~0.02 s) instead of paying for synthesis — measured
# 1.76 s for the survey greeting with Kokoro `af_heart`, which is dead air in a
# live call.
#
# The text is part of the cache key, so it has to be what dograh actually sends:
# the *rendered* greeting, i.e. the `| fallback:` arm of each
# {{initial_context.…}} template, since an inbound call arrives without context.
# One character off is a cache miss, and the miss is silent — check the shim log
# for "already cached" after a call rather than trusting this file by eye.
#
