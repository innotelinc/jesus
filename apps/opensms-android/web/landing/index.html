OpenSMS — Turn an Android phone into a local SMS API server.

An Android application that exposes the phone's SMS capability through a small local API, so a script or a service can send and receive messages without a paid gateway. No account, no advertisements and no telemetry.

View on GitHub Quick start 
./gradlew assembleDebug

An SMS gateway is a monthly bill and a third party.

A phone you already own is the gateway, on your own network.

Inbound messages disappear into a handset.

The API delivers them to the service that needs them.

Messaging tools want a cloud account.

There is no account and no telemetry; the device is the boundary.
