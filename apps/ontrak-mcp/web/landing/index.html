ontrak-mcp — A dependency-free MCP client and tool bridge for agent consoles.

The Model Context Protocol layer from OnTrak Genie, extracted so it can be reviewed and versioned on its own: a client that starts stdio servers, lists their tools and calls them, plus a reference server. Node's standard library only.

View on GitHub Quick start 
npm install ontrak-mcp

An SDK can be larger than the protocol it wraps.

Four methods implemented directly, with no runtime dependency.

A tool server can die mid-call.

The call is rejected with the reason and the next call starts a fresh child.

A server-initiated request can block forever.

Unknown client methods are answered, not dropped.
